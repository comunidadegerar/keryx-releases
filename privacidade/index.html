Política de privacidade

Atualizada em 26 de outubro de 2026

O KERYX é um programa instalado no computador da igreja. Ele não tem contas de usuário e os desenvolvedores não mantêm um servidor que receba as músicas, os cultos ou a mídia da igreja.

O que fica no computador

Músicas, cultos, temas, mídia, anotações e configurações ficam guardados no próprio computador, numa pasta de dados do KERYX.

Acesso ao Google Drive

Se a igreja escolher sincronizar os seus computadores, ela entra com uma conta Google dentro do KERYX. O KERYX pede só estas permissões:

  • drive.appdata: uma pasta oculta, exclusiva do KERYX, no Drive dessa conta. O KERYX guarda ali as músicas, os cultos e a mídia da igreja para os outros computadores da igreja receberem. O KERYX não vê, não lê e não altera nenhum outro arquivo do Drive.
  • openid e email: para mostrar em qual conta o computador está conectado.

Esses dados vão direto do computador da igreja para o Google Drive da própria igreja. Não passam por servidores dos desenvolvedores, não são vendidos, não são usados para publicidade e não são compartilhados com ninguém. O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

A autorização fica guardada de forma protegida no computador (com a proteção de dados do Windows). Para retirá-la, use "Sair" no KERYX ou remova o KERYX em myaccount.google.com/permissions. A pasta oculta pode ser apagada pelo Drive (Configurações › Gerenciar apps).

Quando o KERYX usa a internet

  • Procurar atualizações do programa (GitHub).
  • Ler ou instalar edições da Bíblia, procurar letras de músicas e vídeos do YouTube, quando o operador pede.
  • Sincronizar com o Google Drive, quando a igreja liga.
  • Relatar um problema: só quando o operador envia um relato, o texto dele e um arquivo de diagnóstico (registros do programa, sem as músicas nem a mídia) vão para os desenvolvedores, para corrigir o problema.
